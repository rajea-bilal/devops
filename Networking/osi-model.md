# OSI Model

## Why Communication Models Exist

- Provide a standard framework.
- Allow application independence from hardware.
- Simplify upgrades.
- Enable innovation at individual layers.

---

## OSI Layers

1. Physical
2. Data Link
3. Network
4. Transport
5. Session
6. Presentation
7. Application

---

## Layer 1 – Physical

- Transmits raw bits.
- Media:
  - copper
  - fiber
  - wireless
- Devices:
  - NICs
  - cables
  - switches
- No addressing.

---

## Layer 2 – Data Link

- Node-to-node delivery.
- Frames data.
- Uses MAC addresses.
- Devices:
  - switches
  - bridges

---

## Layer 3 – Network

- Routes packets.
- Uses IP addressing.
- Devices:
  - routers

---

## Layer 4 – Transport

- End-to-end delivery.
- Protocols:
  - TCP
  - UDP

---

## Layer 5 – Session

- Establishes sessions.
- Maintains connections.
- Terminates sessions.

---

## Layer 6 – Presentation

- Formatting.
- Encryption.
- TLS/SSL.

---

## Layer 7 – Application

- Provides network services to apps.
- Protocols:
  - HTTP
  - FTP
  - SMTP
